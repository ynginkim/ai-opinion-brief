Anthropic

Anthropic, Claude가 ‘꿈’으로 기억을 고치는 법 공개 (anthropic.com) 원문

  • Anthropic이 Claude가 세션 사이에 기억을 남기고 정리하는 방식을 엔지니어링 블로그에 풀었다.
  • 쉬는 시간에 지난 기록을 다시 읽고 메모를 고치는 과정을 ‘드리밍(dreaming)’이라 부른다. 틀린 메모를 바로잡자 포켓몬 게임에서 막혔던 길을 통과했다.
  • 회사 문서 약 35만 개로 위키를 만들게 했더니, 정리 세션을 2번에서 128번으로 늘리자 점수가 13%에서 48%로 올랐다.
왜 에이전트에 메모리를 붙이고 있다면, 기록 규칙을 빡빡하게 정하기보다 판단은 모델에 맡기고 정리·검증 단계를 따로 두는 쪽을 검토해 보자.
Mitchell Hashimoto

Mitchell Hashimoto, 터미널 엔진 libghostty 1.0 공개 (mitchellh.com) 원문

  • Ghostty를 만든 Mitchell Hashimoto가 터미널 에뮬레이션 C 라이브러리 libghostty-vt 1.0을 냈다. 이제 C ABI가 안정 버전으로 고정된다.
  • JetBrains IDE 터미널이 이미 이 라이브러리로 돈다. 사용자는 1,250만 명이 넘는다.
  • herdr, cmux 같은 에이전트 코딩 도구도 터미널을 새로 짜지 않고 libghostty 위에 올렸다.
왜 에이전트용 터미널이나 TUI 도구를 만든다면, 에뮬레이터를 직접 짜기 전에 libghostty부터 써 보자.
Dylan Patel / SemiAnalysis

SemiAnalysis “GPU 돈줄이 막혀도 공급 과잉은 아니다” (x.com / semianalysis) 원문

  • SemiAnalysis는 GPU 금융이 빡빡해지면 공급 과잉보다 임대료가 버티는 쪽이 더 그럴듯하다고 봤다.
  • 2027년에 새로 들어올 데이터센터 약 50GW 가운데 위험한 물량은 많아야 2~3GW라고 추정했다.
  • 1년짜리 H100 계약 가격은 2026년 3월보다 약 21% 올랐다고 했다.
왜 ‘AI 거품이 꺼지면 GPU가 남아돈다’에 베팅하기 전에, 1년 계약 단가가 어디로 가는지부터 확인하자.
Garry Tan

Garry Tan “새 모델이 나오면 에이전트 스킬을 지운다” (x.com) 원문

  • YC 대표 Garry Tan이 에이전트 스킬은 평가를 돌려 가며 다듬어야 한다고 썼다.
  • 모델이 나올 때마다 좋아지니, 필요 없어진 스킬은 지우면 된다고 했다.

왜 모델을 바꿨다면, 예전 모델 약점을 메우려 붙인 프롬프트와 스킬을 평가로 다시 걸러 보자.
Andrej Karpathy

Karpathy, 유튜브 추천 글을 3분 만에 사이트로 (x.com / karpathy.ai) 원문

Richard Sutton

Sutton “계산만 쏟아붓는다고 지능이 되진 않는다” (x.com) 원문

  • 강화학습을 개척한 Richard Sutton이 X에 짧은 의견을 올렸다.

Latent Space, Anthropic 상장 서류를 투자자 눈으로 뜯어보다 (youtube.com / latent.space) 원문

  • Latent Space가 Altimeter의 Jamin Ball과 Anthropic 상장 서류(S-1)를 읽는 주말 특집을 냈다.
