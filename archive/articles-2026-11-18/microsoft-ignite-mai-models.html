Satya Nadella · Microsoft · 2026-11-18 Seoul

Microsoft Ignite, 싼 자체 모델 일곱 개

원문 · Microsoft AI · Book of News · Satya Nadella X

한눈에

Microsoft가 연례 행사 Ignite를 열었다. Microsoft AI(MAI) 조직이 새 모델 묶음을 공개했다.

Satya Nadella는 기술 발전을 사람과 조직의 실제 성과로 바꾸는 게 목표라고 했다.

주요 모델 (Microsoft 발표 기준)

  • MAI Code 2: 일상 코딩 4개 벤치 평균에서 GPT-6.1 Sol의 98%, 가격은 약 40%
  • MAI Code 2 Flash: 대량 반복 코딩용, GitHub Copilot에서 사용 가능
  • MAI Cyber 2 Flash: CyberGymE2E에서 GPT-6 Astra 수준, 작업당 비용은 2% 미만
  • MAI Image 2.7: 이미지 편집용
  • Decision 1.1: 분류·라우팅용 결정 모델, Gemma 기반
  • Maia 200: 2세대 자체 AI 칩, 와트당 토큰 1.7배

Microsoft는 이 모델들이 기초 과학 연구나 아주 긴 에이전트 작업에는 아직 맞춰지지 않았다고 스스로 밝혔다.

보안 메시지

MAI는 키노트에서 2027년 이후 가장 중요한 과제로 에이전트 보안, 정렬, 격리를 꼽았다.

공격 도구가 싸지고 흔해졌으니, 방어 에이전트도 24시간 돌릴 만큼 싸야 한다는 논리다. AI 투명성 이니셔티브도 함께 발표했다.

왜 중요한가

프론티어 랩은 더 똑똑한 모델로 싸운다. Microsoft는 “충분히 좋은데 훨씬 싼” 모델로 다른 판을 노린다.

기업 고객 입장에서는 일마다 다른 모델을 골라 쓰는 게 기본이 되고 있다.

어떻게 바뀌나

MAI Code 2 Flash는 곧 OpenRouter, Vercel 등에도 올라간다. 저가 코딩 모델 경쟁이 더 치열해질 것이다.
