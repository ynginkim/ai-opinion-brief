DevDay — dots·Sol·Ultrafast 현장 로그

원문 · simonwillison.net

한눈에

Willison이 Fort Mason DevDay 2026을 라이브 블로그로 정리했습니다. Altman 키노트의 제품 스택 — dots, ChatGPT Spaces, GPT-6.1 Sol, Ultrafast, Decisions API — 을 현장에서 한 줄로 이어 붙인 기록입니다.

OpenAI가 개인 에이전트·가격·보안을 하루 키노트에 몰아넣은 지도를, 커뮤니케이터가 바로 그린 버전입니다.

배경

DevDay 당일에는 공식 블로그(Sol·dots)와 보도(출시 보류)가 동시에 쏟아집니다. 라이브 블로그는 그 사이를 키노트 순서로 이어 줍니다.

Muse급 개인 에이전트 레이스 한가운데서 OpenAI가 dots로 맞대응한 날의 현장감이 핵심입니다.

무슨 일 / 핵심 내용

dots는 Astra 기반 소비자·엔터프라이즈 에이전트. ChatGPT Spaces와 함께 나왔고, Pro/Enterprise부터. Willison은 이를 Muse급 맞대응으로 읽습니다.

GPT-6.1 Sol은 ~Astra 체급에 가격 약 1/5. Ultrafast 추론은 최대 ~300 tok/s. Decisions API는 구조화된 선택 — Jev 체급의 결정 모델 자리에 가깝습니다.

그 밖에 Codex Security Cloud, Agents API(Computer Use), Sign in with ChatGPT, 플러그인, Sites 업그레이드, OpenAI Marketplace. Pro 500과 $200 Pro 플랜 복귀, Dots는 Pro/Enterprise부터.

세션 노트로는 Sites 호스팅 800만, Codex Security CLI/패치 루프(Daybreak), WebMCP vs Computer Use 비교도 적혀 있습니다.

숫자·스펙

  • Ultrafast: 최대 ~300 tok/s.
  • Sol 6.1: ~Astra · 약 1/5가(공식과 동일 프레임).
  • Sites: 호스팅 800만.
  • Pro: Pro 500 · $200 Pro 플랜 복귀. Dots는 Pro/Enterprise부터.

왜 중요한가

공식 페이지를 다 읽기 전에, 하루치 키노트를 한 타임라인으로 훑을 수 있는 1차 현장 로그입니다. dots/Spaces 에이전트 스택과 Sol·Ultrafast·Decisions의 가격·속도 축이 한눈에 들어옵니다.

Decisions API는 긴 글을 쓰지 않고 구조화된 선택·점수를 뽑는 자리에 가깝습니다. Lenny 쪽에서 떠오른 Jev “거의 공짜 분류·라우팅”과 같은 경제권으로 읽힙니다. Ultrafast ~300 tok/s는 인터랙티브 에이전트 체감용 속도 카드입니다.

Codex Security Cloud와 Agents API Computer Use는 “코딩 에이전트 + 보안 루프 + 컴퓨터 조작”을 한 키노트에 올린 조합입니다. Sign in with ChatGPT·플러그인·Marketplace는 플랫폼 락인·생태계 축. Sites 800만 호스팅은 이미 깔린 배포 표면이 있다는 숫자입니다.

Pro 500·$200 Pro 복귀와 Dots Pro/Enterprise 시작은 가격·패키징 신호입니다. 무료 대중보다 헤비 유저·조직이 먼저 에이전트 스택을 받게 설계된 날입니다. 출시 보류 뉴스와 교차해서 읽으면, “낸 것”과 “안 낸 것”의 경계가 더 선명해집니다.

세션 메모의 WebMCP vs Computer Use도 실무 분기입니다. 구조화된 도구 호출로 갈지, 화면을 직접 조작하는 쪽으로 갈지. Agents API가 둘을 어떻게 섞는지는 공식 문서와 이 라이브 로그를 같이 보는 편이 빠릅니다.

하루 키노트를 다 외울 필요는 없습니다. 개인 에이전트(dots/Spaces), 미드 가격 체급(Sol), 속도(Ultrafast), 결정 모델(Decisions), 보안·컴퓨터 사용(Codex Security/Agents) — 이 다섯 바구니만 집어도 DevDay 지도는 충분합니다.

그래서 뭐

개발자는 Sol·Ultrafast·Decisions·Agents API 순으로 무엇을 먼저 붙일지 고르면 됩니다. 개인 에이전트 관심이면 dots·Spaces 롤아웃(Pro부터)을 공식 문서와 교차해 보면 됩니다.

출시 보류 뉴스와 키노트 풍성함은 같이 읽어야 합니다. Willison 로그는 “나온 것”의 지도이고, 보류는 “안 나온 것”의 신호입니다.
