Anthropic (공식 발표) · 2026-10-08 Seoul

Claude Haiku 5.5, Luna와 같은 값에 점수는 더 높다

원문 · anthropic.com

한눈에

Anthropic이 Claude Haiku 5.5를 공개했다. 지금까지 낸 작은 모델 중 가장 싸고 빠르고 성능도 가장 높다고 했다. 요약, 대화 압축, 데이터베이스 조회, 분류처럼 짧고 반복되는 일에 맞춘 모델이다.

코딩에선 Opus 5.5나 Sonnet 5.5 아래에서 일하는 하위 에이전트로 쓰라고 권했다. 속도가 중요한 실시간 고객 상담이나 브라우저 조작에도 맞다고 했다.

가격 (100만 토큰당)

  • Haiku 5.5, 10만 토큰 이하: 입력 0.10달러, 출력 0.50달러
  • Haiku 5.5, 10만 토큰 초과: 입력 0.50달러, 출력 2.50달러
  • Haiku 4.5: 입력 1.00달러, 출력 5.00달러

Haiku 4.5 요청의 90%가 10만 토큰 이하였다. 새 토크나이저 때문에 같은 일에 토큰을 조금 더 쓰는 점까지 따져도, 평균 운영 비용은 약 75% 줄어든다고 Anthropic은 설명했다.

성능 (Haiku 5.5 / Haiku 4.5 / GPT-6 Luna)

  • OSWorld 2.1 오프라인 부분(컴퓨터 사용): 72.4% / 15.7% / 48.9%
  • Terminal-Bench 4.0(터미널 코딩): 39.2% / 0.0% / 16.4%
  • GDPval-AA v2.1(실무 지식 작업): 1620 / 735 / 1437

Haiku 계열 중 처음으로 노력 단계(effort)를 고를 수 있다. 비용을 아낄지 성능을 더 낼지 사용자가 정한다. 복잡한 코딩은 여전히 Sonnet 5.5와 Opus 5.5가 낫다고 Anthropic도 적었다.

보호장치

정렬 평가는 Haiku 4.5보다 거의 모든 항목에서 좋아졌다. 사이버 보호장치는 Haiku 4.5보다 엄격하다. 방어 작업은 Sonnet 5.5보다 넓게 허용하지만, 침투 테스트처럼 공격에 가까운 기법은 막는다.

같이 바뀐 것

Sonnet 5.5의 캐시 읽기 값은 100만 토큰당 0.20달러에서 0.10달러로 내렸다. 에이전트 작업 대부분에서 Sonnet 5.5가 약 20% 싸진다.

이번 주부터 Max 5x 구독자는 매달 100달러, Max 20x는 200달러, Team은 최대 500달러의 API 크레딧을 받는다. Python과 TypeScript SDK에는 컴퓨터 사용과 브라우저 사용 기능이 베타로 들어갔다.

왜 중요한가

작은 모델은 호출 횟수가 많아 단가 차이가 크게 쌓인다. Haiku 4.5는 GPT-6 Luna보다 열 배 비쌌는데, 이번에 10만 토큰 이하 구간에서 값이 같아졌다.

어떻게 바뀌나

Claude Platform에선 claude-haiku-5-5로 바로 쓸 수 있다. AWS, Google Cloud, Microsoft Azure에서도 제공한다.
