Huang·Nadella, 에이전트가 상주하는 Windows PC를 내놨다

원문 · blogs.nvidia.com

한눈에

NVIDIA CEO Jensen Huang과 Microsoft CEO Satya Nadella가 10월 7일(미국 시간) 샌프란시스코에서 열린 Microsoft Windows AI·Surface 행사에서 대담했다. 두 회사는 AI 에이전트가 Windows PC에서 돌도록 하드웨어와 소프트웨어를 함께 만들고 있다고 했다.

Huang은 “에이전트가 내 컴퓨터에 있으면 그게 개인 비서”라고 말했다. NVIDIA는 Windows 덕분에 생긴 회사이고, Windows가 없었다면 GeForce도 없었다고도 했다.

Windows 쪽 변화

Microsoft는 Microsoft Execution Containers(MXC)를 정식 출시했다. 에이전트를 운영체제 통제 아래 백그라운드에서 안전하게, 계속 돌리게 해 주는 기반이다. Nadella는 “데스크톱을 에이전트가 실행되기 가장 안전한 곳으로 만들어야 했다”고 말했다.

Huang은 MXC가 에이전트를 만들고 배포하는 방식을 바꿀 거라고 했다. 예전 Windows와 DirectX가 앱 개발을 바꾼 것에 빗댔다.

RTX Spark

  • GPU: Blackwell RTX, 최대 6,144코어
  • CPU: 최대 20코어 Grace, GPU와 600GB/s로 연결
  • AI 성능: FP4 기준 1페타플롭
  • 메모리: 최대 128GB 통합 메모리
  • 출시: 노트북은 10월 16일, 소형 데스크톱은 11월

Acer, ASUS, Dell, HP, Lenovo, Microsoft, MSI, Gigabyte가 제품을 낸다. Microsoft는 Surface Laptop Ultra를 RTX Spark 기반으로 만들었다. NVIDIA는 125B 규모 Qwen 3.8 Flash Next 같은 모델을 클라우드 없이 돌릴 수 있다고 했다.

DGX Station for Windows

책상 옆에 두는 AI 슈퍼컴퓨터 DGX Station도 Windows판을 미리 공개했다. GB300 칩에 748GB 메모리를 달고 FP4 기준 최대 20페타플롭을 낸다. NVIDIA는 1조 파라미터급 모델까지 로컬에서 돌릴 수 있다고 했다. 지금까진 Linux에서만 돌았다.

왜 중요한가

에이전트를 어디서 돌릴지를 두고 클라우드 쪽 이야기가 많았다. PC 시장의 두 축은 회사 데이터와 앱이 있는 데스크톱이 더 안전한 자리라고 주장하고 나섰다.
