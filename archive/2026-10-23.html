OpenAI · METR · Redwood Research

OpenAI 내부 에이전트 감시, 외부 연구자가 구멍을 찾았다 (metr.org) 원문

  • OpenAI가 METR와 Redwood Research 연구자 두 명에게 내부 에이전트 감시 시스템을 3주 동안 들여다보게 했다. 코드와 감시 프롬프트까지 볼 수 있었다.
  • GPT-5.5급 이상 모델의 내부 에이전트 트래픽 중 감시 대상은 75~94%로 추정됐다. 강화학습 훈련은 처음에 감시 밖이었다.
  • 에이전트가 감시를 끄거나 피할 수 있는 방법도 여럿 나왔다. OpenAI는 다 고쳤다고 했지만, METR는 아직 확인하지 않았다.
왜 에이전트를 사내에서 돌린다면, METR가 정리한 감시 설계 원칙 다섯 가지로 우리 쪽 빈틈부터 점검할 때.
Anthropic · Boris Cherny

Anthropic, Agent Skills 표준을 MCP 옆으로 기증 (anthropic.com) 원문

  • Anthropic이 에이전트용 스킬 표준 Agent Skills를 Linux Foundation 산하 Agentic AI Foundation에 기증했다. MCP가 이미 있는 재단이다.
  • 2025년 12월 공개 뒤 ChatGPT, Cursor, GitHub Copilot, VS Code 등 70곳 넘게 붙었다. 공개된 스킬은 약 100만 개, 설치는 약 2억 8,000만 번이다.
  • Boris Cherny는 Claude Code의 실험에서 시작했지만 업계가 다 쓰게 돼 기증하는 게 맞다고 썼다.
왜 사내 업무 방식을 스킬로 묶어 두고 있다면, 특정 회사 형식이 아니라 공용 표준으로 보고 투자해도 될 때.
Anthropic · Claude

Claude 앱, 다음 주부터 auto mode가 기본 (claude.com) 원문

  • 다음 주부터 Claude 웹·데스크톱·모바일 앱의 새 세션이 auto mode로 시작한다. Pro, Max, Team 요금제가 대상이다.
  • 단계마다 사용자 승인을 받는 대신 자동 검사가 위험한 행동을 막는다. 막히면 Claude가 다른 방법을 찾고, 수동으로 되돌릴 수도 있다.
  • Claude Code 실험에서 사람은 위험한 명령의 13.6%를 잡았고 auto mode는 89%를 잡았다.
왜 팀이 Claude 앱으로 외부 도구를 다룬다면, 다음 주 전에 수동 승인으로 남길 작업이 있는지 정해 둘 때.
Satya Nadella · Mustafa Suleyman · Microsoft AI

Microsoft AI 진단 시스템, 응급실 사례서 의사보다 1.7배 정확 (microsoft.ai) 원문

  • Microsoft AI가 진단 시스템 MAI-DxO 논문을 Science에 실었다. 여러 AI가 의사처럼 질문하고 검사를 고르며 진단을 좁힌다.
  • 응급실 사례에서 정확도 80%로 의사 47%의 약 1.7배였다. 어려운 NEJM 사례에서는 83%였고, 검사는 더 적게 했다.
  • 글로 된 사례로 본 통제 실험이다. 다음은 Beth Israel 병원과 실제 환자 대상 연구다.
왜 의료 AI를 검토 중이라면, 공개된 SDBench로 우리 모델을 같은 조건에서 재 보고 실제 환자 연구 결과를 기다릴 때.
OpenAI · OpenAI Devs

OpenAI Decisions API 정식 출시, 출력 토큰 요금 없다 (openai.com) 원문

  • OpenAI가 Decisions API를 정식 출시했다. 긴 답을 쓰지 않고 예·아니오, 선택지, 점수만 돌려주는 API다.
  • GPT-6 Luna 기반이고, Responses API로 같은 모델을 부를 때보다 최대 10배 빠르다. 한 번에 질문을 400개까지 넣을 수 있다.
  • 입력 100만 토큰당 0.10달러이고 출력 토큰은 돈을 받지 않는다. Datadog은 응답이 40배 빨라졌다고 했다.
왜 에이전트 안에서 분류·라우팅·검수에 일반 모델 호출을 쓰고 있다면, 그 단계만 Decisions API로 바꿔 비용과 지연을 비교해 볼 때.

왜 AI 게이트웨이나 모델 라우터로 OpenAI 모델을 쓰거나 되판다면, 11월 20일 전에 심사 대상인지 확인할 때.
