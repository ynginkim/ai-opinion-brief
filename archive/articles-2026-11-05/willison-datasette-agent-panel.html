윌리슨, 데이터 옆에 붙는 Datasette Agent 패널 공개

원문 · Simon Willison · datasette-apps

한눈에

사이먼 윌리슨이 Datasette Agent 0.5a0을 냈다. 핵심은 ‘패널’이다.

에이전트 채팅창이 Datasette의 표나 쿼리 화면 옆에 붙어 있다.

왜 중요한가

datasette-apps와 합치면 채팅으로 데이터베이스 앱을 만들 수 있다. 앱을 옆에 띄운 채 말로 계속 고친다.

다음 날 낸 datasette-apps 업데이트에는 보호장치가 들어갔다. 데이터를 바꾸는 쿼리는 사용자가 먼저 승인해야 한다.

어떻게 바뀌나

agent.datasette.io에서 GitHub 계정으로 바로 써 볼 수 있다.

에이전트에게 앱을 맡길 때 읽기와 쓰기 권한을 나누는 방식으로 참고할 만하다.
