Microsoft, 사내 에이전트 하네스를 외부에 판다

원문 · Microsoft 블로그 · Satya Nadella (X, GitHub Universe) · Satya Nadella (X, 실적) · Latent Space AINews

한눈에

Microsoft가 GitHub Universe에서 Copilot 하네스를 외부 개발자에게 내놨다. 하네스는 모델 주변에서 지시, 맥락, 실행 환경, 권한을 챙기는 층이다. GitHub 엔지니어들이 만들었고, 지금은 Copilot Studio, GitHub Copilot 앱, CLI, VS Code가 모두 이 위에서 돈다.

이제 이 하네스를 Microsoft Foundry에서 관리형 서비스로 쓰거나 SDK로 받아 쓸 수 있다. 20개 넘는 최상위 모델을 지원하고, 자기 API 키도 붙일 수 있다.

왜 중요한가

나델라가 앞세운 건 Copilot Fusion이다. 작업 중에 여러 회사 모델을 골라 섞어 쓰는 방식으로, 최상위 수준 품질에 40% 빠르고 비용은 최대 77% 낮다고 했다. 여러 저장소에 걸친 일을 에이전트 여럿에게 나눠 맡기는 Copilot Projects도 함께 나왔다.

독립 측정도 나왔다. Latent Space AINews가 전한 Artificial Analysis 결과에서 Fusion은 Claude Code+Opus 5.5보다 코딩 에이전트 지수가 2점 낮았지만, 과제당 비용은 5.59달러로 11.42달러의 절반 아래였다.

어떻게 바뀌나

Microsoft는 하네스 런타임을 Rust로 옮겨 세션 부담과 첫 응답 시간을 줄였다고 했다. 모델이 자주 바뀌는 상황에서 하네스를 직접 만들고 유지하던 팀은 이를 넘기는 선택지가 생겼다.

같은 날 실적 발표에서 나델라는 Microsoft Cloud 매출이 630억 달러를 넘어 1년 전보다 30% 늘었다고 밝혔다.
