Google DeepMind · Demis Hassabis · Varun Mohan

Gemini 4 Carbon, 독립 평가 1위로 올라섰다 (blog.google) 원문

  • Google DeepMind가 Argon을 낸 지 2주 만에 새 최상위 모델 Gemini 4 Carbon을 공개했다.
  • Artificial Analysis 지수 v5에서 59점으로 1위다. 취약점 찾기 시험 SEC-bench Pro에서는 88.2%를 냈다.
  • 먼저 Fairwind 프로그램의 일부 보안 방어 팀에만 제공하고, 개발자 공개 날짜는 아직 없다.
왜 기본 모델을 바꿀지 고민 중이라면, 개발자 공개 전까지는 지금 모델을 그대로 두고 공개 일정을 지켜볼 때.
Sundar Pichai (Alphabet)

피차이 “앞으로 12개월, AI 개발은 더 빨라진다” (blog.google) 원문

  • Alphabet 3분기 매출이 1년 전보다 25% 늘어 연간 환산 5천억 달러 규모가 됐다.
  • Google Cloud 매출은 103% 늘었다. 자사 모델 API는 분당 약 320억 토큰을 처리한다.
  • 피차이는 AI가 AI 개발을 돕는 재귀적 자기 개선(RSI) 덕에 앞으로 12개월은 더 빨라질 거라고 했다.
왜 AI 도입 계획을 연 단위로 잡고 있다면, 모델이 몇 주 단위로 바뀐다는 전제로 일정을 다시 짤 때.
Satya Nadella (Microsoft)

Microsoft, 사내 에이전트 하네스를 외부에 판다 (blogs.microsoft.com) 원문

  • 나델라가 GitHub Universe에서 Copilot Fusion을 소개했다. 최상위 수준 품질에 40% 빠르고 비용은 최대 77% 낮다고 했다.
  • GitHub이 만든 Copilot 하네스를 Microsoft Foundry에서 관리형 서비스로 쓸 수 있게 했다. 20개 넘는 모델을 한 하네스에서 돌린다.
  • 같은 날 실적 발표에서는 Microsoft Cloud 매출이 630억 달러를 넘어 30% 늘었다고 밝혔다.
왜 에이전트 하네스를 직접 만들어 유지하고 있다면, Foundry의 Copilot 하네스로 넘길 수 있는지 비교해 볼 때.
Boris Cherny · Anthropic

유타주 개발자 71%, Claude Code로 20시간 넘게 아꼈다 (x.com) 원문

  • Anthropic이 미국 조달청(GSA)과 새 계약을 맺어 연방부터 주·지방 정부까지 Claude를 40% 할인한다.
  • Boris Cherny가 소개한 유타주 사례에서는 10개 기관 개발자 34명 중 80%가 30분 안에 개발 환경을 갖췄다.
  • 4주 시범이 끝났을 때 71%가 20시간 넘게 아꼈다고 답했다.
왜 조직에 코딩 에이전트를 들일지 망설인다면, 유타처럼 4주짜리 소규모 시범으로 효과부터 재 볼 때.
Latent Space (swyx · AINews)

Carbon, 종합은 1위지만 코딩 에이전트는 Opus 아래 (latent.space) 원문

  • Latent Space AINews가 Carbon의 독립 평가를 모아 Google이 Artificial Analysis 지수에서 처음 1위에 올랐을 수 있다고 짚었다.
  • 코딩 에이전트 지수는 59점으로 Claude Code와 Opus 5.5 조합의 62점보다 낮다. 지수 과제당 비용은 7.76달러로 Opus 5.5의 10.04달러보다 싸다.
  • 환각 비율은 Argon의 4%에서 11%로 올랐다는 Artificial Analysis 측정도 함께 전했다.
왜 Carbon을 코딩 기본 모델로 바꿀지 고민한다면, 종합 1위보다 코딩 에이전트 점수가 아직 Opus 5.5 아래라는 점부터 볼 때.
Simon Willison

윌리슨 “이번 10월, AI로 재밌는 게임이 된다” (simonwillison.net) 원문

  • 사이먼 윌리슨이 2026년 10월을 바이브 코딩 게임의 전환점으로 꼽았다.
  • Claude Opus 5.5로 직접 즐기는 게임 네 개를 만들었고, 하나에 자기 손이 든 시간은 4시간 이하였다.
  • GPT-6 Astra도 게임은 만들지만 재미를 내는 감각은 아직 Opus 5.5에 못 미친다고 봤다.
왜 주말에 AI 코딩을 시험해 볼 거리를 찾는다면, 작은 브라우저 게임부터 Opus 5.5에 맡겨 볼 때.
Simon Willison

GitHub 병합 PR, 1년도 안 돼 세 배로 (simonwillison.net) 원문

  • 사이먼 윌리슨이 GitHub Universe에서 나온 Octoverse 2026 보고서 숫자를 짚었다.

시그널 대표 “화면 읽는 AI 에이전트가 비밀 대화를 위협한다” (youtube.com) 원문

  • 케빈 루스와 케이시 뉴턴의 새 팟캐스트 Machine Gods가 시그널 대표 메러디스 휘태커를 불렀다.

Lenny's Newsletter (How I AI · Claire Vo)

개인 에이전트 4종 비교, 일은 Grok Bot·생활은 Muse (lennysnewsletter.com) 원문
