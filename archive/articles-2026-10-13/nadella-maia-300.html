Microsoft, Maia 300으로 멀티기가와트 자체 추론 인프라 키운다

원문 · blogs.microsoft.com · @satyanadella · Azure Blog

한눈에

Satya Nadella가 10월 12일, 자체 실리콘에 대한 지금까지 가장 큰 베팅이라고 밝혔다. 2027년부터 Azure Maia 패밀리를 멀티기가와트급으로 키운다. Microsoft 제품과 서비스의 주력 추론 시스템으로 쓴다고 했다.

같은 날 Scott Guthrie가 공식 블로그에 세부 내용을 올렸다. Maia 200은 이미 생산 워크로드를 돌리고 있고, Maia 300은 2027년 생산 배포를 시작한다.

Maia 300이 뭐가 다른가

Microsoft는 Maia 300이 선도 GPU 기반 시스템보다 메가와트당 토큰을 40% 더 낸다고 했다. 긴 컨텍스트 추론, 지연에 민감한 대화, 여러 단계가 이어지는 에이전트 작업을 겨냥한 추론용 시스템이라고 설명했다.

96가속기를 꽉 채운 구성에서는 Maia 200보다 랙 단위 토큰 처리량이 최대 7배라고 했다. 랙 전력 한도는 167킬로와트다.

Maia 200은 이미 돌아가고 있다

Maia 200은 미국·유럽·호주에 배포 중이다. Microsoft Copilot을 포함해 생산 워크로드를 돌리고 있고, 연말까지 GitHub Copilot과 Microsoft Foundry도 이어질 예정이라고 했다.

Teams·Copilot·Cowork의 내장 AI에서는 선도 GPU 인프라보다 와트당 토큰이 최대 1.7배라고 밝혔다. OpenAI 모델, Microsoft MAI 모델, 주요 오픈소스 모델 패밀리를 함께 돌린다고 했다.

왜 중요한가

클라우드 사업자가 자체 추론 칩을 ‘보조’가 아니라 자사 제품의 주력으로 못 박은 발표다. 멀티기가와트 규모로 키운다는 말은, 전력·데이터센터 계획과 칩 로드맵이 한 줄로 묶였다는 뜻이다.

어떻게 바뀌나

Azure·Copilot 쪽 추론 비용을 보는 사람이라면, 2027년 이후 Maia가 주력이 된다는 전제를 인프라·단가 계산에 넣을지 보면 된다. 벤치마크 세부와 아키텍처는 Azure 기술 블로그와 기술 논문을 직접 보는 편이 낫다. 이 글에서는 Microsoft가 밝힌 규모·효율 숫자와 일정만 적었다.
