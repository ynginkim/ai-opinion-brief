How To Write With An LLM

원문 · simonwillison.net

무슨 일

Thomas Ptacek의 “LLM으로 글쓰기” 규칙을 Willison이 소개합니다. 핵심은 Rule Number One: LLM이 제안한 문장은 한 단어도 쓰지 말 것. 교정·팩트체크·시소러스만 허용하자는 지적 PPE에 가깝습니다.

Willison의 실천

본인도 블로그 본문을 LLM이 쓰게 하지 않고, 맞춤법·문법·팩트체크와 가끔 유의어만 맡깁니다. LLM 특유의 “냄새” 나는 표현을 피하려는 규율과도 맞다고 적습니다.

도구 쪽

Ptacek은 개인 카피에디팅 도구 스크린샷과 시작용 프롬프트를 공유했고, HN 댓글에 시스템 프롬프트도 올렸습니다. 규범이 선명한 한 줄로 정리된 점이 포인트입니다.

한 줄 Ptacek 규칙—교정·팩트체크만, 제안 문장은 한 단어도 금지—를 Willison도 동의하며 LLM 글쓰기 규범의 선명한 한 줄로 남긴다.
