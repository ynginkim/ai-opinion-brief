GPT-6.1 Sol, 6배 값에 최대 8배 빠른 Ultrafast

원문 · community.openai.com · OpenAIDevs X · 모델 문서

한눈에

OpenAI가 GPT-6.1 Sol에 Ultrafast 모드를 붙였다. 같은 모델을 더 빠르게 돌려 주는 요금 등급이다. API, Codex, ChatGPT Work에 순차 적용된다.

OpenAI는 Astra에 가까운 성능을 기본 Sol보다 최대 8배 빠른 속도로 낸다고 소개했다. GPT-6.1 Sol 발표 때 예고한 기능이 이번에 나온 것이다.

가격과 대상

  • API 입력: 100만 토큰당 12달러 (기본 2달러)
  • API 출력: 100만 토큰당 60달러 (기본 10달러)
  • 기본 요금의 6배, GPT-6 Astra 대비 약 1.2배
  • Codex·ChatGPT Work: Pro 500, 사용량 기반 Enterprise, 크레딧 기반 Edu (Enterprise는 관리자가 켜야 함)
  • 미국·EU 데이터 상주 지원

왜 중요한가

OpenAI는 이 모드를 장애 디버깅, 앱을 오가는 에이전트, 몇 초가 중요한 실시간 서비스용이라고 설명했다.

모델은 그대로인데 속도만 따로 판다는 점이 눈에 띈다. 같은 답을 더 빨리 받는 값이 6배다. 그래서 대부분의 일에는 기본 모드가 여전히 경제적이다.

어떻게 바뀌나

API에서는 Responses API에 service_tier를 ultrafast로 지정하면 된다. 같은 날 GPT-6.1 Sol Fast와 GPT-6 Luna Fast에도 EU 데이터 상주가 추가됐다.
