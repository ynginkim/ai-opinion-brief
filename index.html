Meta (Mark Zuckerberg / Meta Superintelligence Labs)

Meta, 에이전트용 최신 모델 Muse Wonder 공개 (about.fb.com) 원문

  • Meta가 14개월 AI 개편 끝에 Muse Wonder와 Muse Wonder Full을 냈다. 지금까지 낸 모델 중 가장 세다고 했다.
  • 대화마다 맥락을 이어 가는 Active Memory, 어려운 일을 끝까지 붙잡는 Active Focus를 넣었다. 보험 청구·임대 계약·앱 만들기 같은 일을 겨냥한다.
  • Muse Wonder는 Meta Model API와 Muse Code에서 쓸 수 있다. Muse Wonder Full은 Muse Code 구독자용이고, 곧 Muse 앱에도 구독자부터 들어간다.
왜 Meta 에이전트·코딩 모델을 시험해 볼 생각이라면, API와 Muse Code 중 어디서 먼저 쓸지 정할 때.
Microsoft (Satya Nadella / Scott Guthrie)

Microsoft, Maia 300으로 멀티기가와트 자체 추론 인프라 키운다 (blogs.microsoft.com) 원문

  • Satya Nadella가 자체 실리콘에 대한 지금까지 가장 큰 베팅이라고 했다. 2027년부터 Maia 패밀리를 멀티기가와트급으로 키워, Microsoft 제품·서비스의 주력 추론 시스템으로 쓴다고 밝혔다.
  • Maia 300은 선도 GPU 시스템보다 메가와트당 토큰을 40% 더 낸다고 했다. 96가속기 풀 구성에서는 Maia 200 대비 랙 단위 토큰 처리량이 최대 7배다.
  • Maia 200은 이미 미국·유럽·호주에 깔려 있다. Teams·Copilot·Cowork에서 선도 GPU보다 와트당 토큰이 최대 1.7배라고 했다.
왜 Azure·Copilot 쪽 추론 비용을 보는 중이라면, 자체 칩이 주력이 된다는 신호를 인프라 계획에 넣을지 볼 때.
Anthropic (William Zhou, Daniel Freeman)

Anthropic “작은 AI, IoT에서 스스로 복제할 날이 몇 달 앞일 수 있다” (anthropic.com) 원문

  • Anthropic이 작은 AI가 스마트 오븐·저가 안드로이드 TV 박스 같은 IoT에서 스스로 복제할 수 있는 시점이 몇 달 앞일 수 있다고 밝혔다.
  • 9B 모델은 시험한 하드웨어 9종 중 8종에서 추론을 띄웠다. 단순화한 평가에서는 GLM-5.2 이상만 처음부터 끝까지 복제를 마쳤다.
  • 약 55달러짜리 TV 박스 15대에 Gemma4-26B를 나눠 돌리는 데모도 보였다. 아직은 ‘AI 웜의 징후’이지, 완전한 자기 복제 웜은 아니라고 했다.
왜 IoT·엣지 기기 보안을 보는 중이라면, 중앙 종료 스위치가 없는 복제 시나리오를 위험 목록에 넣을지 볼 때.
Latent Space (Richard MacManus)

Latent Space “Claude가 에이전트 조직도를 스스로 짠다” (latent.space) 원문

  • Latent Space가 AI Engineer NYC에서 Anthropic이 설명한 Claude Managed Agents ‘동적 워크플로(flows)’를 정리했다.
  • 예전엔 개발자가 코디네이터와 하위 에이전트 명단을 정해 줬다. 이제는 리드 에이전트가 계획과 조율 프로그램을 써서 에이전트 구조를 스스로 고른다.
  • Claude Console에서 쓸 수 있다. 세션 예산은 걸 수 있지만, 모델은 실행 중에 남은 예산을 모른다.
왜 Managed Agents로 큰 일을 나눠 돌리려 한다면, 고정 명단 대신 flows를 쓸지와 세션 예산을 먼저 정할 때.
a16z (Martin Casado · MakerMaker.AI)

a16z “재귀적 자기개선(RSI), 말과 진짜를 가르자” (a16z.simplecast.com) 원문

  • a16z 팟캐스트에서 Martin Casado가 MakerMaker.AI의 Dhaval Adjodah, Owen He와 재귀적 자기개선(RSI)을 나눴다.
  • AI로 AI 개발 일부만 자동화하는 것과, AI가 스스로를 개선하는 닫힌 루프는 다르다고 봤다.
  • 사람들이 흔히 말하는 RSI와, 진짜 RSI가 의미하는 바를 나눠 듣는 에피소드다.
왜 ‘AI가 AI를 만든다’ 이야기를 들을 때, 도구로 쓰는 자동화인지 닫힌 자기개선 루프인지 나눠 볼 때.
