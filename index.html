Anthropic

Anthropic, Claude와 함께 박테리아 ‘볼트’ 입자 구조 첫 공개 (anthropic.com) 원문

  • Anthropic 생물학 연구팀이 원핵세포 쪽 볼트 입자의 3D 구조를 처음 풀었다. 볼트는 기능이 아직 수수께끼인 커다란 단백질 통이다.
  • Claude가 단백질 검색, DNA 설계, 정제 방법, 현미경 데이터 처리를 맡았다. 정제는 사흘에서 90분으로 줄었다.
  • 첫 구조 모델은 34시간 만에 나왔다. 보통이면 몇 주 걸리는 일이라고 했다.
왜 AI가 실험실 연구의 처음부터 끝까지 붙은 사례다. 기초 생물학의 속도가 바뀔 수 있다.

올트먼 “미래의 통제권을 초지능에 넘기면 안 된다” (x.com) 원문

  • 올트먼이 “사람은 언제나 미래를 통제해야 한다”고 X에 썼다.
  • AI가 보상할 만하다고 정한 일을 사람이 하는 세상에 OpenAI는 반대한다고 했다.
  • 이 원칙이 결국 AI 발전 속도도 묶어야 한다고 했다. 숄레는 “AI는 사람 손의 도구로 남아야 한다”며 동의했다.
왜 OpenAI 대표가 ‘사람의 통제’를 발전 속도보다 앞에 두겠다고 말했다. 앞으로의 결정을 이 말로 재 볼 수 있다.
OpenAI

OpenAI, Codex 코드 리뷰 도구 만든 Pierre 인수 (openai.com) 원문

  • OpenAI가 Code Storage와 오픈소스 Trees·Diffs를 만든 Pierre를 인수한다. Codex 앱에서 파일을 보고 변경을 리뷰할 때 이미 쓰던 도구다.
  • 에이전트가 브랜치를 만들고 배포까지 가는 Git 흐름을 새로 짜겠다는 목표다.
  • 오픈소스는 그대로 열어 둔다. Pierre 투자자인 미첼 하시모토도 축하 글을 올렸다.
왜 코딩 에이전트 경쟁이 모델을 넘어 코드 저장과 리뷰 도구로 번지고 있다.
Google DeepMind

DeepMind, Antigravity에 화학 스킬 붙여 신약 설계를 1시간에 (deepmind.google) 원문

  • DeepMind가 코딩 에이전트 앱 Antigravity에 화학 정보학 스킬을 붙였다.
  • 폐암 약 사례에서 에이전트가 논문 속 화합물 수천 개를 모으고, 효능 모델을 만들고, 새 분자와 합성 경로까지 1시간 안에 냈다.
  • 과학자 1만 명에게 최고 사용 등급을 6개월 무료로 준다.
왜 코딩 에이전트 도구가 과학 실험 책상이 되고 있다. 다만 제안한 분자는 실험으로 확인해야 하는 가설이다.
Simon Willison

윌리슨, 데이터 옆에 붙는 Datasette Agent 패널 공개 (simonwillison.net) 원문

  • 윌리슨이 Datasette Agent 0.5a0을 냈다. 에이전트 채팅창이 표나 쿼리 화면 옆에 붙는다.
  • 채팅으로 데이터베이스 앱을 만들고, 옆에 띄운 채로 계속 고칠 수 있다.
  • 이어 낸 업데이트에서는 앱이 데이터를 쓰는 쿼리를 쓰려면 사용자 승인을 먼저 받게 했다.
왜 에이전트가 앱을 만들 때 ‘쓰기 권한은 사람이 승인’이라는 보호장치를 어떻게 넣는지 보여준다.
a16z

a16z “AI 시대엔 바이아웃보다 벤처가 앞선다” (x.com) 원문

  • a16z의 젠 카는 인터넷, 모바일, 클라우드 때처럼 AI 물결에서도 벤처가 바이아웃을 앞선다고 봤다.
  • 전 세계 바이아웃에서 테크 비중은 2023년 34%에서 2026년 1분기 11%로 떨어졌다.
  • 성장률 중간값은 사모펀드가 산 소프트웨어 3~7%, 상장사 10~16%, 벤처 투자 비상장사 18~30%다.
왜 SaaS를 사서 굴리던 공식이 AI 앞에서 흔들린다는 투자자 쪽 시각이다. 물론 a16z는 벤처 쪽 사람이다.
