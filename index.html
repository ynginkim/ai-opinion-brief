Mark Zuckerberg · Meta

왜 모델 내부를 점검할 도구를 고른다면, “뉴런만 보면 된다”는 주장은 아직 논쟁 중이니 논문이 나올 때까지 기다릴 때.
Grant Sanderson (3Blue1Brown)

Grant Sanderson “지금이 수학에 들어가기 가장 좋은 때” (youtube.com) 원문

  • 3Blue1Brown의 Grant Sanderson이 AI와 수학에 대한 생각을 40분 영상으로 냈다. 수학자가 하는 일과 수학의 가치, 돈이 어디서 오는지를 나눠 따졌다.
  • AI가 증명과 이론까지 더 잘하게 돼도, 문제 푸는 힘과 수학의 즐거움은 사람이 직접 해야 얻는다고 봤다. 수학계 돈의 가장 큰 몫인 강의도 사람 사이 일이라 남는다고 했다.
  • 지금이 좋은 때인 이유는 AI가 아니라고 했다. 수학계가 바뀌어야 한다는 걸 알고 길을 찾는 중이라, 새로 들어온 사람이 방향을 정할 수 있다는 것이다.
왜 수학이나 이론 분야 진로를 고민한다면, 발표를 자주 하고 “내가 수학에서 좋아하는 것”부터 정리해 볼 때.
Terence Tao · Kevin Buzzard 외

Lean 전문가들 “수학 전체 형식화, 서두르면 해롭다”… Tao는 오픈 수학 OS 공개 (terrytao.wordpress.com) 원문

  • Jeremy Avigad, Kevin Buzzard 등 Lean 전문가 7명이 AI로 수학 문헌 전체를 형식화하자는 제안에 답하는 글을 냈다. Terence Tao가 이 글을 블로그에 소개했다.

왜 Lean으로 증명을 옮기거나 공개 모델로 수학 작업을 하려는 연구자라면, SAIR 팀 계정을 신청해 볼 때.
Jim Fan (NVIDIA)

Jim Fan, 로봇이 스스로 기술을 쌓는 ASPIRE 1.0 오픈소스 (x.com) 원문

  • NVIDIA Jim Fan 연구실이 로봇 에이전트 틀 ASPIRE 1.0을 오픈소스로 냈다. 코딩 에이전트가 로봇 제어 코드를 짜고, 실패를 진단해 고치고, 익힌 기술을 쌓아 둔다.
  • Jim Fan은 GPT-6 Astra가 나온 날 백엔드 모델만 바꿨더니 벤치마크가 하룻밤 새 약 99%까지 찼다고 했다.
  • 자체 로봇 시뮬레이션 벤치에서는 Claude Opus 5.5가 Astra를 살짝 앞섰다. Sonnet 5.5는 과제당 12달러로 비용 대비 성능이 가장 좋은 축에 들었다.
왜 로봇 제어를 코드로 짜는 팀이라면, 모델만 바꿔 끼우며 성능을 비교하는 공개 틀로 써 볼 때.
Boris Cherny · Claude Code 팀 (Anthropic)

Claude Code 팀 “코드 90%는 Claude가 쓰고, 리뷰도 기계가 먼저 본다” (claude.dev) 원문

  • Anthropic이 Claude Code 팀의 코드 리뷰 방식을 공개했다. Claude가 Claude Code 코드의 약 90%를 쓰는데, 6~9월 병합된 PR은 두 배 넘게 늘고 되돌린 비율은 40% 넘게 줄었다.
  • 여러 에이전트가 동시에 버그를 찾고, 다른 에이전트들이 투표해 진짜 버그만 남긴다. 사람의 시간은 위험한 변경에 아껴 쓴다.
  • 이 리뷰 기능 Code Review가 Team·Enterprise 요금제에 정식 출시됐다. Boris Cherny는 모든 PR에 돌리고 있고 버그를 거의 다 잡는다고 했다.
왜 에이전트가 짠 코드 때문에 리뷰가 밀린다면, 저장소마다 리뷰 수준(Quick·Standard·Deep)을 다르게 붙여 볼 때.
Satya Nadella · Microsoft Research

Nadella “더 큰 모델보다, 틀리는 곳을 배우는 검증 시스템” (x.com) 원문

  • Microsoft Research가 2~6주 뒤 날씨 예보를 고치는 머신러닝 틀 PBC를 Nature에 실었다. 기존 예보 모델이 늘 틀리는 방향을 배워서 바로잡는 방식이다.

  • Satya Nadella는 앞으로는 더 강한 모델만이 아니라, 모델이 체계적으로 틀리는 곳을 배우는 검증 시스템이 중요할 수 있다고 적었다.

Anthropic (STEM Fellows Program)

  • 정확성은 일반 컴퓨터에서 도는 채점기로 확인했고, 한 증명은 Lean으로도 검증했다. Harvard 연구진과 함께 한 연구이고 논문은 arXiv에 올렸다.
왜 양자 알고리즘을 연구한다면, 회로 설계를 에이전트와 자동 채점기 루프에 맡겨 볼 사례로 볼 때.
