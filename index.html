Michael Nielsen

마이클 닐슨, 딥러닝 입문서를 내렸다 “프론티어 랩에 가지 마라” (neuralnetworksanddeeplearning.com) 원문

  • 마이클 닐슨이 2011~2015년에 쓴 무료 온라인 책 『Neural Networks and Deep Learning』을 내렸다.
  • 그는 프론티어 랩들의 무모한 경쟁 탓에 AI가 자기 예상보다 훨씬 빨리 왔다고 적었다.
  • 책이 있던 자리에는 이유를 담은 글이 올라왔고, 끝에서 그는 프론티어 랩에서 일하지 말라고 썼다.
왜 이 책으로 딥러닝을 배우던 사람은 다른 자료를 찾아야 한다. 랩 밖 유명 연구자가 랩 취업 자체를 말리고 나선 만큼, 안전 논쟁은 더 거칠어질 수 있다.
SemiAnalysis · Dylan Patel

SemiAnalysis “에이전트 추론 이익률, Trainium3가 GB300 앞섰다” (newsletter.semianalysis.com) 원문

  • SemiAnalysis가 AWS Trainium3의 추론 성능과 칩 구조를 뜯어본 긴 분석을 냈다.
  • 사용자당 초당 135토큰 속도에서 Trainium3 서버의 이익률은 73.5%로, 2위 GB300(53%)보다 높았다고 계산했다.
  • 다만 첫 토큰이 나오기까지 걸리는 시간(TTFT)은 일부 구간에서 아직 GB300에 밀린다.
왜 에이전트를 많이 돌리는 회사라면 추론 견적에 Trainium도 넣어 볼 만하다. 달러당 성능 1위는 여전히 NVIDIA Vera Rubin이다.
Varun Mohan · Google Antigravity

Antigravity, 자동 모드의 쓸데없는 승인 요청 15% 더 줄였다 (x.com) 원문

  • Varun Mohan이 추수감사절 다음 날 Google Antigravity 새 버전이 나왔다고 X에 알렸다.
  • 자동(Auto) 모드에서 굳이 필요 없는 승인 요청을 15% 더 줄였다.
  • GitHub PR 링크를 채팅에 붙이면 상태·브랜치·댓글을 바로 보여 주는 기능도 들어갔다.
왜 Antigravity에 긴 작업을 맡기는 사람은 중간에 확인 버튼을 누를 일이 줄어든다. PR 리뷰를 같은 창에서 이어 가기도 쉬워졌다.
Dwarkesh Podcast · Daniel Kokotajlo · Ege Erdil

Kokotajlo와 Erdil, 초지능 시기는 갈렸지만 결론은 비슷했다 (dwarkesh.com) 원문

  • Dwarkesh Patel이 AI 2027 저자 Daniel Kokotajlo와 Google DeepMind 연구자 Ege Erdil의 대담을 올렸다.
  • Kokotajlo는 2027년에 AI 연구가 완전히 자동화될 가능성이 반보다 조금 높다고 봤고, Erdil은 3년 안 지능 폭발 확률을 10~20%로 잡았다.
  • 그래도 Erdil은 20%라도 결과가 나쁘면 대비해야 한다고 말해, 둘은 생각보다 많이 동의했다.
왜 초지능 시기를 두고 고민 중이라면 양쪽 근거를 한 번에 들을 수 있다. 2027년 매출·로봇·게임 예측도 나와 내년에 맞춰 보기 좋다.
Hard Fork (NYT) · Max Read · Terence Tao

테렌스 타오 “지금 AI는 통찰 없이 답만 준다” (nytimes.com) 원문

  • NYT 팟캐스트 Hard Fork에서 객원 진행자 Max Read가 테렌스 타오를 인터뷰했다.
  • 타오는 지금 AI가 이해와 통찰 없이 답만 준다며, 창문 없는 헬기로 폭포까지 곧장 날아가는 것과 같다고 했다.
  • 랩들이 외부 학자와 협업하지 않고, 증명을 동료 심사 없이 공개한다는 점도 짚었다.
왜 AI 수학 성과를 볼 때 “풀었다”와 “이해했다”를 나눠 보라는 조언이다. 41분 분량이고 YouTube로도 볼 수 있다.
Latent Space · Jeff Barg (Clay)

Clay “4천만 개 회사 전부 걸러도 1,500달러면 된다” (latent.space) 원문

  • Latent Space가 영업·마케팅 데이터 회사 Clay의 AI 책임자 Jeff Barg를 인터뷰했다.
  • Clay DB의 4천만 개 회사를 고객 조건에 맞는지 분류하는 데 약 1,500달러면 된다는 계산을 소개했다.
  • Clay 자체 에이전트와 Claude Code 같은 외부 도구로 쓰는 비율이 이미 50 대 50에 가깝다고 했다.
왜 서비스에 에이전트를 붙이려는 팀이라면 CLI와 외부 에이전트 지원부터 챙길 만하다. 자체 모델 학습은 추론비가 1천만~1억 달러는 넘어야 득이라는 기준도 참고할 만하다.
