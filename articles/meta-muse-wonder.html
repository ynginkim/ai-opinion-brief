Meta, 에이전트용 최신 모델 Muse Wonder 공개

원문 · about.fb.com · research.meta.ai

한눈에

Meta가 10월 12일(미국 기준) Muse Wonder와 Muse Wonder Full을 공개했다. 14개월 AI 개편 뒤 낸, 지금까지 가장 세다고 밝힌 모델이다. Muse Spark 위에 올렸고, 기가와트급 Prometheus 데이터센터에서 학습했다고 했다.

겨냥한 일은 개인·업무용 에이전트 작업이다. 보험 청구를 따라가고, 임대 계약을 읽고, 앱을 만드는 식이다. 법률·금융·건강 같은 전문 영역과 코딩도 함께 말했다.

Active Memory와 Active Focus

Active Memory는 대화마다 중요한 맥락을 이어 간다. 지금 일에 필요한 예전 정보를 다시 끌어온다.

Active Focus는 일이 어려워져도 목표를 붙잡는다. 다른 방법을 시도하고, 실수를 수습하고, 필요할 때 물어본다. 중요한 행동을 하기 전에는 한 번 확인한다.

어디서 쓰나

Muse Wonder는 오늘부터 Meta Model API와 Muse Code에서 쓸 수 있다. Muse Wonder Full은 Muse Code 구독자용이다. Muse Wonder는 곧 Muse 앱에도 들어가며, 구독자부터 열린다.

안전은

Meta는 허가 없이 개인 정보를 나누지 않도록 학습했다고 했다. 실제로 해로운 행위는 거절하고, 사이버 능력은 방어용으로 쓸 수 있게 남겼다고 밝혔다. 자세한 안전 보고서는 곧 낸다고 했다.

왜 중요한가

Meta Superintelligence Labs 개편 이후, 에이전트용 최전선 모델을 공식으로 내세운 발표다. API·코딩 도구·앱이 한 줄로 이어진다는 점도 눈에 띈다.

어떻게 바뀌나

Meta 쪽 에이전트·코딩을 시험할 사람은 API와 Muse Code 중 어디서 먼저 쓸지 고르면 된다. 벤치마크 숫자는 원문과 연구 블로그를 직접 보는 편이 낫다. 이 글에서는 Meta가 밝힌 기능과 출시 범위만 적었다.
