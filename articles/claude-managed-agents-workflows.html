Claude 에이전트, 한 번에 최대 1,000개로 일을 나눈다

원문 · x.com · 문서: 워크플로 실행 · 문서: 멀티에이전트 · Claude Code Projects

한눈에

Anthropic이 10월 9일(미국 시간) Claude Managed Agents에 동적 워크플로를 공개 베타로 넣었다. Managed Agents는 Anthropic이 운영하는 에이전트 실행 API다. 새 기능은 여러 에이전트를 한꺼번에 굴리는 방식이다.

어떻게 돌아가나

큰일을 받으면 에이전트가 워크플로를 직접 쓴다. 워크플로는 여러 에이전트를 단계별로 돌리고 결과를 모으는 프로그램이다. 서버가 이것을 백그라운드에서 실행하는 동안, 원래 에이전트는 다른 일을 하거나 차례를 끝낼 수 있다.

문서가 드는 예는 수백 건의 문서 검토와 여러 출처 교차 확인이다. 에이전트들이 동시에 일하니, 하나가 차례로 처리할 때보다 빨리 끝날 수 있다.

한도

  • 동시에 일하는 에이전트: 실행당 64개
  • 실행 전체에서 띄우는 에이전트: 최대 1,000개
  • 실행 수명: 기본 24시간
  • 세션당 동시에 열린 실행: 기본 10개

어떻게 바뀌나

실행 자체에는 요금이 없다. 대신 각 에이전트가 쓴 토큰이 모델 요금대로 청구된다. 세션 예산에 닿으면 열린 실행이 모두 멈춘다. 에이전트 수가 많아지는 만큼 예산을 먼저 정해 두는 게 안전하다.

켜려면 에이전트 정의의 multiagent 항목을 multiagent_20261001 타입으로 정하면 된다. 이 타입에서는 하위 에이전트 위임과 동적 워크플로가 기본으로 켜진다. 같은 날 Anthropic은 Claude Code Projects 대기 명단의 Pro·Max 사용자를 모두 받아들였다.
