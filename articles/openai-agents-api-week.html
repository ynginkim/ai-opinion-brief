OpenAI Agents API, 시간 감각과 자동 검토가 붙었다

원문 · OpenAI Developers (X) · Steve Coffey (X)

한눈에

OpenAI Agents API 팀이 한 주 동안 기능 다섯 개를 내놨다. 공식 개발자 계정이 팀원 스티브 코피의 글을 인용해 알렸다.

무엇이 바뀌었나

Auto Review는 명령을 실행하기 전에 나쁜 행동인지 먼저 살핀다. Codex에 있던 기능과 같다.

Async Compaction은 대화 압축을 뒤에서 처리한다. 압축은 긴 대화를 줄여 맥락 창에 맞추는 일이다. 세션이 덜 멈춘다.

Time awareness는 실험 기능이다. 모델이 시간이 흐르는 것을 안다. 그래서 ‘CI 수정은 10분 안에 끝내라’ 같은 지시를 더 잘 따른다.

세션 도중에도 도구 목록을 언제든 바꿀 수 있다.

시스템 프롬프트는 이제 모든 세션에서 자동으로 캐시된다. 비용과 응답 시간이 줄어든다.

왜 중요한가

오래 도는 에이전트는 안전, 속도, 시간 관리, 비용이 모두 문제다. 이번 업데이트는 그 네 가지를 한 번에 건드린다.

특히 시간 감각은 ‘언제 멈출지’를 모델이 스스로 판단하게 해 준다.

어떻게 바뀌나

Time awareness는 아직 실험 단계다. 실제 작업에서 얼마나 잘 지키는지는 써 보며 확인해야 한다.
