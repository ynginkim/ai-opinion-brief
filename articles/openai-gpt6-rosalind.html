OpenAI, 생명과학 전용 GPT-6 Rosalind를 열었다

원문 · OpenAI 도움말 · API 변경 기록 · API 가격표

한눈에

OpenAI가 10월 30일 API 변경 기록에 GPT-6 Rosalind를 올렸다. 생명과학 연구용 모델이다.

생물학 추론과 과학 도구 사용을 합쳤다. 아무나 쓸 수는 없고, 심사를 통과한 기관만 쓴다.

누가, 어디서 쓰나

GPT-Rosalind 접근은 두 등급으로 나뉜다. Research는 최전선 생물학 연구용이고, Discovery는 문헌 검토나 데이터 분석 같은 일상 연구용이다.

GPT-6 Rosalind는 Research 등급 기관만 쓴다. Discovery 승인으로는 쓸 수 없다.

쓸 수 있는 곳은 Work, Codex, 그리고 따로 승인받은 API다. 일반 채팅 탭에는 없다.

Enterprise 워크스페이스에서는 2주 동안 관리자 미리보기로 시작한다. 이 기간에는 기본값이 꺼짐이다.

얼마인가

API 모델 이름은 gpt-6-rosalind다. 100만 토큰당 입력 15달러, 출력 75달러, 캐시 입력 1.5달러다.

기존 Rosalind Research와 Discovery 모델은 입력 5달러, 출력 25달러다.

왜 중요한가

생물학 능력은 연구에도 쓰이고 악용될 수도 있다. OpenAI는 이런 모델을 신뢰 접근 프로그램 뒤에 두는 방식을 계속 쓰고 있다.

이번에는 그 대상이 GPT-6급으로 올라왔다. 도움말 문서는 표적 발굴, 유전체 분석, 실험 설계 같은 초기 연구에 가장 쓸모 있다고 적었다.

어떻게 바뀌나

API 접근은 내부 연구 도구용으로만 허용된다. 고객용 제품에 넣는 것은 아직 안 된다.

미국 대학 연구실은 Rosalind Academic Plan으로 신청할 수 있지만, 이 플랜에는 API 접근이 없다.
