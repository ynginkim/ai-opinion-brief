마리오 츠흐너, 프롬프트 하나로 만든 JSON 스키마 검사기 pi-schema

원문 · Mario Zechner (X) · 후속 글 (X)

한눈에

마리오 츠흐너가 pi-schema를 공개했다. JSON 스키마를 만들고 검사하는 라이브러리다.

eval()을 쓸 수 없는 환경에서도 돈다. 클로저로 일종의 즉석 컴파일을 흉내 낸다고 설명했다.

어떻게 만들었나

그는 AI가 분위기대로 짜고, 성능을 조금씩 끌어올리게 해 만들었다고 했다. 목표는 빠르고, 정확하고, 메모리와 번들 크기가 작은 것이다.

후속 글에서는 컴파일 방식만큼 빠르면서 eval 없이 정확한, JSON 스키마 검사의 이상형에 가깝다고 적었다. 자신은 잘 짠 프롬프트 하나만 줬다며 쓸모없어진 기분이라고 했다.

어떻게 바뀌나

11월 1일에는 pi가 더 이상 typebox에 의존하지 않는다고 알렸다. 도구 인자 등에 계속 쓸 수는 있지만 굳이 쓸 이유가 없다고 했다.

같은 날 그는 에이전트에서 가장 큰 문제는 신뢰라고 썼다. 기존 테스트와 적합성 검사 묶음이 있으면 그 신뢰가 올라간다는 입장이다.
