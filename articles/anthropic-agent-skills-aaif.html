Anthropic, Agent Skills 표준을 MCP 옆으로 기증

원문 · Anthropic · X @bcherny · Simon Willison

한눈에

Anthropic이 Agent Skills를 Agentic AI Foundation(AAIF)에 기증했다. 스킬은 에이전트에게 특정 일을 하는 방법을 폴더 하나로 묶어 주는 형식이다. 설명서와 스크립트, 참고 자료가 함께 들어간다.

AAIF는 Linux Foundation 아래 있는 재단이다. Anthropic이 먼저 기증한 MCP도 여기 있다. 이번에 이름과 로고, GitHub 조직, agentskills.io 사이트까지 넘겼다.

숫자

  • 도입한 에이전트 플랫폼: 70곳 이상 (ChatGPT, Cursor, GitHub Copilot, VS Code 등)
  • 공개된 스킬: 약 100만 개
  • 설치: 약 2억 8,000만 번
  • 핵심 관리자: David Soria Parra, Mahesh Murag
  • AAIF 새 프로젝트: Agent Skills, OpenAI Open Responses, Hugging Face OpenEnv 등 4개 (총 10개)

왜 중요한가

스킬은 Claude Code에서 실험으로 시작했다. 지금은 경쟁사 제품에서도 같은 형식으로 쓴다. 표준을 한 회사가 쥐고 있으면 다른 회사가 마음 놓고 따르기 어렵다.

Boris Cherny는 X에 “업계 여러 곳이 받아들였으니 MCP 옆에 기증하는 게 더 맞다고 봤다”고 썼다. Simon Willison은 작년 12월 이미 이런 흐름을 예상했다고 적었다.

어떻게 바뀌나

이제 스킬 형식은 재단의 공개 절차로 바뀐다. 한 번 만든 스킬을 여러 에이전트 제품에서 그대로 쓰는 일이 더 쉬워진다.

같은 날 OpenAI의 Open Responses도 AAIF 프로젝트가 됐다. 에이전트를 잇는 기본 규격이 경쟁사끼리 공유하는 쪽으로 모이고 있다.
