Latent Space, OpenAI가 말하는 Codex 새 작업 방식

원문 · Latent Space

한눈에

AI Engineer Code Summit 첫날, OpenAI의 Dominik Kundel과 Charlie Guo가 “Codex로 일하는 새 방법” 워크숍을 열었다.

Guo는 6월 이후 Codex에 넣은 기능이 너무 많아 화면에 다 못 담았다고 했다.

클라우드로 넘기기

Codex는 2025년 5월 클라우드 에이전트로 시작했다. 하지만 Kundel은 클라우드 쪽 경험이 한동안 어색했다고 인정했다.

9월 DevDay에서 Codex Cloud 2가 나오며 달라졌다. 환경을 한 번 만들어 두면 여러 작업을 격리된 복사본에서 돌린다.

이제 로컬 Codex에게 “이 작업을 클라우드로 넘겨”라고 말하면 된다. Kundel은 로컬과 클라우드가 “합쳐지는 중”이라고 했다.

음성으로 지휘하기

Guo는 음성을 받아쓰기 도구가 아니라 지휘 화면처럼 쓴다고 했다.

스레드 확인, 새 작업 시작, 다른 앱에서 정보 가져오기를 모두 말로 한다.

Kundel은 출근길에 자기 dot과 대화하며 PR을 띄워 두고, 도착해서 검토한다고 했다.

dots는 아직 낯설다

dots는 세션 사이에도 곁에서 돕는 OpenAI의 개인 에이전트다.

Guo는 Codex를 많이 쓰는 사람에게도 dots가 아직 어색하다고 털어놨다.

그래도 쓸모는 세 가지라고 했다. 놓친 걸 짚어 주는 안전망, 일을 던져 두는 곳, 어디서나 곁에 있는 존재다.

왜 중요한가

코딩 도구 경쟁이 모델 성능에서 작업 흐름 설계로 옮겨 가고 있다.

Kundel의 마지막 조언은 “지금 방식에 너무 매이지 말라”였다. 그만큼 일하는 방식이 빨리 바뀐다는 뜻이다.
