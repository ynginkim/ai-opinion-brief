AINews “Haiku 5.5, 같은 값이면 Luna보다 낫다”

원문 · latent.space

한눈에

Latent Space의 AINews가 10월 8일 호 머리기사로 Claude Haiku 5.5를 다뤘다. 약 1년 만의 Haiku 새 버전이다. AINews는 값은 GPT-6 Luna와 같고 성능은 낫다고 정리했다.

독립 평가

  • Artificial Analysis 지능 지수(최고 단계): 43점, 이전 Haiku보다 26점 상승
  • GLM-5.3 Flash 42점, Gemini 3.8 Flash 41점, GPT-6 Luna 38점보다 높다
  • 2.8조 매개변수 오픈 모델 Kimi K3(44점)와 비슷하다
  • Claude Sonnet 5.5 최고 단계(56점)보다는 13점 낮다

출시 당일 반응

Cursor는 짧은 요청에서 Haiku 4.5보다 열 배 싸다고 했다. GitHub Copilot 팀은 많은 코딩 작업에서 Claude Sonnet 5와 비슷한 결과를 더 적은 토큰과 단계로 냈다고 전했다.

Devin을 만드는 Cognition은 FrontierCode 1.1에서 58.4%를 얻어, 작업당 비용 약 8분의 1로 Sonnet 5를 앞섰다고 했다. Opus 5.5가 이끄는 작업 밑에서 보조로 쓰라고 권했다.

같이 바뀐 것

Sonnet 5.5 캐시 읽기 값은 절반으로 내렸다. Max와 Team 구독자는 매달 API 크레딧을 받는다. Python과 TypeScript SDK엔 컴퓨터·브라우저 사용 도구가 들어가, 개발자가 클릭과 입력을 반복하는 루프를 직접 짤 필요가 없어졌다.
