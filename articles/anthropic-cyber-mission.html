Anthropic (공식 발표) · 2026-10-08 Seoul

Anthropic, 전력망·오픈소스 지키는 Cyber Mission 시작

원문 · anthropic.com

한눈에

Anthropic이 10월 8일 Cyber Mission을 시작했다. 방어하는 쪽에 도구와 연구, 자금을 대는 장기 사업이다. 첫 두 분야는 기반 시설과 오픈소스 소프트웨어다.

공격자는 이미 사이버 능력이 뛰어난 AI를 쓰고 있다. 반면 방어 도구는 필요한 사람에게 아직 다 닿지 않았다는 게 Anthropic의 설명이다.

기반 시설 방어

발전소, 상수도, 공장, 교통망은 수십 년 쓰는 제어 장비로 돌아간다. 이를 운영 기술(OT)이라고 부른다. 멈추고 패치하기 어려워서 알려진 취약점이 몇 년씩 남는다.

새로 만든 Critical Infrastructure Defense Program은 운영사들이 믿고 맡기는 보안 업체에 최신 Claude 모델, 현장 엔지니어, 위협 연구를 제공한다. 창립 파트너는 Accenture, Booz Allen, CrowdStrike, Deloitte, Dragos, Hitachi, Insane Cyber, Nozomi Networks, Palo Alto Networks, PwC, Rockwell Automation 11곳이다.

6월에 시작한 주·지방 정부용 방어 프로그램은 지금 미국 주의 절반 넘는 곳에 Claude 모델과 기술 지원을 주고 있다.

오픈소스: OSS Scanner

Anthropic은 Project Glasswing에서 널리 쓰는 오픈소스 수백 개를 스캔했다. 찾은 취약점은 사람이 검토한 뒤 관리자에게 비공개로 알렸다.

OSS Scanner는 신청한 프로젝트를 가장 강한 모델로 주기적으로 무료 점검한다. Google OSS-Fuzz에서 착안했다. 보고서마다 공격 재현 예시, 설명, 가능하면 수정안이 붙는다.

보고서는 모델이 만들고 사람 검토 없이 바로 간다. 그만큼 빠르지만 심각도 등급이 틀리는 식의 오류가 섞일 수 있다. Anthropic은 정탐률이 90%를 넘을 것으로 봤다.

Python Software Foundation, OpenSSF, Apache Software Foundation 같은 오픈소스 재단에도 자금을 댔다.

왜 중요한가

Anthropic은 2년쯤 뒤엔 AI가 방어 쪽에 유리해질 거라고 내다봤다. 하지만 당장은 취약점을 악용하는 비용만 떨어졌고, 확인하고 고치는 일은 여전히 느리다. Glasswing에서도 발견부터 수정까지 몇 달씩 걸린 경우가 많았다.

이번 주 초 Cyber Verification Program 확대에 이은 두 번째 사이버 발표다.
