ChatGPT 구독료만큼 API 크레딧도 준다

원문 · Simon Willison 블로그

한눈에

OpenAI가 고가 ChatGPT 구독자에게 API 크레딧을 주기 시작했다. 사이먼 윌리슨이 짧은 글로 이 소식을 정리했다.

무슨 혜택인가

월 100달러, 200달러, 500달러 요금제 구독자는 같은 금액만큼 크레딧을 받는다. 이 크레딧은 API 조직 하나에 붙여 쓸 수 있다.

윌리슨은 이달 초 Anthropic이 Max와 Team 구독자에게 준 혜택과 거의 같다고 봤다. Anthropic 쪽 크레딧은 기한이 지나면 사라진다.

왜 중요한가

두 선두 회사 모두 구독료 일부를 개발 예산으로 돌려주는 셈이다. 개인 개발자는 API를 시험해 볼 문턱이 낮아진다.

윌리슨도 이제 구독으로 비용이 해결되니 공개 데모를 더 내 볼 수 있겠다고 했다.
