Steinberger, 에이전트 루프로 OpenClaw 프런트엔드를 2주 만에 갈아엎다

원문 · X @steipete (Solid 이전) · X @steipete (tsrs)

한눈에

OpenClaw를 만든 Peter Steinberger가 에이전트로 큰 코드 이전을 끝냈다고 X에 썼다. 웹 프런트엔드를 Lit에서 Solid 2.0으로 옮기는 작업이다. 2주 전 에이전트 루프를 한 번 걸어 두고 거의 자동으로 돌렸다.

숫자

  • Lit을 완전히 걷어 내기까지: 약 6일
  • Solid다운 패턴으로 다듬기: 약 일주일 더
  • 나온 PR: 약 600개
  • 사람의 개입: 이틀에 한 번 세션 확인

결과물은 JS와 CSS 크기가 줄었고, 화면 갱신을 더 잘게 제어할 수 있게 됐다. 전체가 더 빠릿해졌다고 했다.

컴파일러도 바꿨다

같은 주말 그는 TypeScript 컴파일러를 tsrs로 바꿨다. 그대로 갈아 끼우면 되고, OpenClaw에서는 약 5배 빨랐다. 그는 Microsoft가 팀을 꾸려 2년 걸려 TS 컴파일러를 Go로 다시 썼는데, 이제는 에이전트로 몇 주 만에 더 나은 것을 만든다고 했다.

왜 중요한가

프레임워크 이전은 개발팀이 가장 미루는 일 가운데 하나다. 실제 서비스 코드에서 에이전트가 2주 동안 600개 PR로 해냈다는 구체적인 사례다.

어떻게 바뀌나

사람은 코드를 한 줄씩 쓰기보다 루프를 걸고 중간 점검을 하는 쪽으로 옮겨 간다. 큰 리팩터링을 시도하는 부담도 그만큼 줄어든다.
