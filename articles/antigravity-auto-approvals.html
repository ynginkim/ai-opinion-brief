Antigravity, 자동 모드의 쓸데없는 승인 요청 15% 더 줄였다

원문 · Varun Mohan X · Google Antigravity X

한눈에

Google Antigravity를 이끄는 Varun Mohan이 11월 27일(미국 시간) 새 릴리스 소식을 올렸다. 추수감사절 바로 다음 날이다.

자동 모드에서 불필요한 승인 요청을 15% 더 줄였고, GitHub 연동을 기본 기능으로 넣었다고 했다.

무엇이 바뀌었나

자동 모드는 에이전트가 사람 확인 없이 작업을 이어 가는 모드다. 확인 요청이 줄면 사람이 자리를 비워도 일이 덜 멈춘다.

GitHub 쪽은 PR 링크다. 채팅에 PR 링크를 붙이면 본문 안에 작은 표시로 들어간다. 마우스를 올리면 상태와 브랜치, 댓글이 보인다. 연결된 PR은 Overview 메뉴에서 모아 볼 수 있다.

왜 중요한가

코딩 에이전트의 불편은 대부분 “멈춰서 물어보는 순간”에서 나온다. 그 횟수를 숫자로 줄였다는 점이 이번 업데이트의 요점이다.

Mohan은 하루 전 지난 한 주 동안 일본에서 새 사용자가 많이 늘었다고도 적었다.

어떻게 바뀌나

PR 확인 때문에 브라우저로 넘어갈 일이 줄어든다. Antigravity 안에서 코딩부터 리뷰 확인까지 이어 가는 흐름이 쉬워졌다.
