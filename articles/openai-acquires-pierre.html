OpenAI, Codex 코드 리뷰 도구 만든 Pierre 인수

원문 · OpenAI · Mitchell Hashimoto X

한눈에

OpenAI가 Pierre라는 작은 회사를 인수한다고 밝혔다.

Pierre는 코드 저장 서비스 Code Storage와 오픈소스 도구 Trees, Diffs를 만들었다. Codex 앱에서 파일을 둘러보고 변경점을 보는 화면이 이 도구로 돌아간다.

왜 중요한가

에이전트가 코드를 동시에 많이 쓰면 Git 주변이 버거워진다. OpenAI는 이번 주 사내 소스 관리 백엔드 Pando도 소개했다.

이제 경쟁은 모델 성능만이 아니다. 사람이 에이전트의 코드를 얼마나 빨리 보고 고칠 수 있느냐도 중요해졌다.

Pierre의 Diffs는 리뷰 화면에서 바로 코드를 고칠 수 있다. 빠른 문법 강조 도구 Highlights도 냈다.

어떻게 바뀌나

OpenAI는 Codex를 ‘에이전트가 첫 브랜치를 만들고 배포까지 가는 곳’으로 만들겠다고 했다.

오픈소스는 계속 열어 두고, Code Storage 기능은 Codex로 옮긴다. 인수는 규제 승인 뒤 마무리된다.
