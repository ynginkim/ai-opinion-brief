OpenAI, 어디서 쓰든 같은 안전 규칙 적용한다

원문 · OpenAI

한눈에

OpenAI 모델은 ChatGPT와 API 말고도 여러 길로 쓰인다. Google Cloud 같은 클라우드, 협력사 제품, 재판매사가 있다. OpenAI는 이 모든 경로에 같은 안전 기준을 걸겠다고 밝혔다.

글에는 GPT-6 Astra 같은 최신 모델이 넓게 퍼질수록 오용을 막는 규칙도 같이 따라가야 한다는 문제의식이 담겼다.

바뀌는 것

  • 새 이용 정책 적용: 2026년 11월 20일
  • 라우터·AI 게이트웨이: OpenAI 모델에 직접 접근을 주면 OpenAI 심사와 승인 필요
  • SafetyID: 신원을 모른 채 조사에서 최종 사용자를 구분
  • Private Safety Processing: 협력사용 안전 처리 방식

왜 중요한가

지금까지는 경로마다 안전 장치 수준이 달랐다. 한쪽에서 막힌 사용자가 다른 쪽으로 옮겨 가면 그만이었다. 같은 기준을 걸면 이런 빈틈이 줄어든다.

어제 OpenAI 모델이 Google Cloud에 들어간 것과도 이어진다. 경로가 많아질수록 규칙을 하나로 맞출 필요가 커진다.

어떻게 바뀌나

게이트웨이 사업자에게는 부담이 생긴다. OpenAI 심사를 받아야 계속 모델을 제공할 수 있다.

개발자는 쓰는 경로가 심사 대상인지 확인해야 한다. 최종 사용자를 구분하는 SafetyID를 붙이는 작업도 필요할 수 있다.
