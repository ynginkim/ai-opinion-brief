Claude, MCP 2주년에 스킬·긴 작업·데스크톱 앱까지 붙였다

원문 · Claude 블로그 (Skills over MCP) · Claude 블로그 (Install as app) · Claude X (플러그인) · Boris Cherny X

한눈에

Anthropic이 MCP 2주년을 맞아 Claude의 MCP 기능을 크게 늘렸다. 핵심은 Skills over MCP다. MCP 서버가 도구 목록뿐 아니라 그 도구를 잘 쓰는 법까지 스킬로 함께 보낸다.

스킬은 필요할 때만 불러와서 컨텍스트를 아낀다. 서버가 업데이트되면 스킬도 같이 바뀐다. 사용자는 따로 설치할 게 없다. Claude Code를 만든 Boris Cherny는 “Claude Code가 MCP 서버 쓰는 법을 처음부터 안다”며 반겼다.

긴 작업과 확인 절차

Tasks를 쓰면 서버가 오래 걸리는 작업이나 에이전트 루프 전체를 뒤에서 돌린다. Claude는 그동안 다른 일을 하다 결과를 받는다.

Elicitation은 중간에 사용자 확인을 받는 기능이다. Supabase는 유료 프로젝트를 만들기 전에 비용을 확인받는다. GitHub는 에이전트가 저장소를 지우기 전에 이름을 직접 입력하게 한다.

두 기능은 Pro, Max, Ultra에서 정식 출시됐다. 파일을 서버로 넘기는 File Uploads는 곧 나온다.

같은 날 나온 것들

  • 플러그인: 커넥터와 스킬을 하나로 묶었다. 1만 개 넘게 있고 Free부터 Ultra까지 쓸 수 있다.
  • Install as app: Claude 아티팩트를 Mac·Windows 앱으로 설치한다. 컴퓨터에 접근하려면 사용자 허락을 받아야 한다.

MCP SDK 월간 다운로드는 7억 건을 넘었다고 Anthropic은 밝혔다.

왜 중요한가

MCP는 도구를 연결하는 규격에서 에이전트끼리 일을 주고받는 규격으로 바뀌고 있다. 이 기능들은 MCP 오픈 스펙의 일부라서 Claude가 아닌 다른 호환 클라이언트에서도 쓸 수 있다.
